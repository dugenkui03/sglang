1.1.1 DefaultModelLoader

作用：默认模型加载器，支持从不同类型的权重文件加载模型；先创建模型和参数，再加载实际权重。

继承结构：

      → ABC
          → object

本节方法：load_model()、load_weights_and_postprocess()。

1.1.1.1　load_model()

方法说明：加载模型权重的核心入口。先调用 _initialize_model() 创建模型，再调用 load_weights_and_postprocess() 加载实际权重。

带注释的核心代码：

def load_model(self, *, model_config, device_config):
    target_device = torch.device(device_config.device)
    quant_config = _get_quantization_config(model_config, self.load_config)

    with set_default_torch_dtype(model_config.dtype):
        with target_device:
            # NOTE 创建模型相关对象与参数空间，尚未加载实际权重。
            model = _initialize_model(
                model_config, self.load_config, quant_config
            )

        # NOTE 加载实际权重，并执行加载后的处理。
        self.load_weights_and_postprocess(
            model,
            # 返回权重生成器；遍历时读取权重，按需准备或下载文件。
            self._get_all_weights(model_config, model),
            target_device,
        )

    return model.eval()

1.1.1.2　load_weights_and_postprocess()

方法说明：调用模型的 load_weights() 加载权重，然后遍历模块，执行各计算实现需要的加载后处理。

带注释的核心代码：

@staticmethod
def load_weights_and_postprocess(model, weights, target_device):
    # NOTE 调用模型自身的加载方法，填充先前创建的参数。
    model.load_weights(weights)

    for _, module in model.named_modules():
        quant_method = getattr(module, "quant_method", None)
        if quant_method is not None:
            # 执行加载后处理，例如重排或量化；具体行为由实现决定。
            with device_loading_context(module, target_device):
                quant_method.process_weights_after_loading(module)

1.1.2.1　create_weights()

方法说明：给 VocabParallelEmbedding 创建 weight 参数并注册到层上；把 weight_loader 等加载属性保存到该参数上，供后续填入实际权重。

带注释的核心代码：

def create_weights(
    self, layer, input_size_per_partition, output_partition_sizes,
    input_size, output_size, params_dtype, **extra_weight_attrs,
):
    # NOTE 为本卡 embedding 权重分配未初始化的参数空间。
    weight = Parameter(
        torch.empty(
            sum(output_partition_sizes),
            input_size_per_partition,
            dtype=params_dtype,
        ),
        requires_grad=False,
    )
    set_weight_attrs(weight, {"input_dim": 1, "output_dim": 0})

    # NOTE 创建 weight 参数，并注册到 embedding 层。
    layer.register_parameter("weight", weight)

    # NOTE 把 embedding 层的 weight_loader 保存到 weight 参数对象上。
    set_weight_attrs(weight, extra_weight_attrs)
