# 1.9 模型加载(Model Loading)

> **文档索引(Documentation Index)**
>
> 完整文档索引：[llms.txt](https://docs.sglang.io/llms.txt)。通过此文件查找所有可用页面，再进一步阅读。

> 控制 SGLang 如何加载模型权重(Model Weights)：加载格式(Load Formats)、模型加载器额外配置(Model Loader Extra Config)、多线程加载(Multithreaded Loading)、预取(Prefetching)，以及远程与流式加载器(Remote/Streaming Loaders)。

`--model-path` 选择用于提供服务的检查点(Checkpoint)；`--load-format` 和下文的权重加载参数控制如何将这些权重读入内存。要从云端对象存储(Object Storage，如 S3/GCS/Azure)流式加载权重，参见[从对象存储加载模型(Loading Models from Object Storage)](https://docs.sglang.io/docs/advanced_features/object_storage)。

## 加载流程(How Loading Works)

SGLang 根据 `--load-format` 选择加载器(Loader)，未指定具体格式时，根据检查点或模型路径自动检测。默认的 `auto` 加载器读取 `safetensors`，如果不可用，则回退到 PyTorch `.bin` 格式。

```bash
python -m sglang.launch_server \
  --model-path Qwen/Qwen3.6-35B-A3B \
  --load-format auto
```

部分格式会被自动检测，并覆盖 `auto` 的选择：

- 检测到 Mistral 原生检查点(Native Checkpoint)时，使用 `mistral` 加载。
- 检测到 `.gguf` 模型路径时，使用 `gguf` 加载。
- 对象存储的统一资源标识符(Uniform Resource Identifier，URI)，即 `s3://`、`gs://`、`az://`，使用 `runai_streamer` 加载。
- 远程 URI 使用 `remote` 加载。

## 加载格式(Load Formats)

通过 `--load-format` 设置：

| 格式(Format) | 说明(Description) |
|---|---|
| `auto` | 默认选项。优先加载 `safetensors`，如果不可用，则回退到 PyTorch `.bin` 格式。 |
| `safetensors` | 加载 safetensors 格式的权重。 |
| `pt` | 加载 PyTorch `.bin` 格式的权重。 |
| `npcache` | 加载 PyTorch 格式的权重，并保存 NumPy 缓存(Cache)，以加快后续加载；仅支持 `.bin` 检查点。 |
| `dummy` | 使用随机值初始化权重，用于性能分析(Profiling)。 |
| `sharded_state` | 每个张量并行(Tensor Parallelism，TP)工作进程(Worker)只读取预先切分后属于自己的分片(Shard)，而非完整检查点，从而加快大型 TP 模型的加载；创建分片检查点的方法见 `examples/runtime/engine/save_sharded_state.py`。 |
| `fastsafetensors` | 使用 `fastsafetensors` 迭代器(Iterator)加载 safetensors 权重。 |
| `layered` | 逐层加载权重，可以在加载下一层之前对当前层进行量化(Quantization)，降低峰值内存占用(Peak Memory Usage)。 |
| `gguf` | 加载 GGUF 格式的权重；根据 `.gguf` 模型路径自动检测。 |
| `bitsandbytes` | 使用 bitsandbytes 量化加载权重。 |
| `mistral` | 加载 Mistral 原生格式检查点；此类检查点会被自动检测。 |
| `flash_rl` | 使用 SGLang 原生 FP8 量化加载 BF16/FP16 检查点，用于强化学习(Reinforcement Learning，RL)训练；需要设置 `--rl-quant-profile`。 |
| `runai_streamer` | 从固态硬盘(Solid-State Drive，SSD)、共享文件系统(Shared Filesystem)或对象存储流式加载权重；参见[从对象存储加载模型](https://docs.sglang.io/docs/advanced_features/object_storage)。 |
| `remote` | 从远程键值存储(Key-Value Store，KV Store)或文件系统连接器(Filesystem Connector)加载张量(Tensor)；根据远程 URI 自动检测。 |
| `remote_instance` | 通过网络从另一个正在运行的 SGLang 实例，即种子实例(Seed)，拉取权重，而非从磁盘读取；通过 `--remote-instance-weight-loader-*` 参数配置。 |

## 模型加载器额外配置(Model Loader Extra Config)

`--model-loader-extra-config` 接收一个 JSON 字符串，并将其传给 `--load-format` 选定的加载器。

```bash
python -m sglang.launch_server \
  --model-path Qwen/Qwen3.6-35B-A3B \
  --model-loader-extra-config '{"enable_multithread_load": true, "num_threads": 16}'
```

| 加载格式(Load Format)<br>右侧配置项适用的 `--load-format` 取值 | 配置键(Key) | 说明(Description) | 默认值(Default) |
|---|---|---|---|
| `auto` / `safetensors` / `pt` / `npcache` | `enable_multithread_load` (bool) | 使用线程池(Thread Pool)并行读取权重分片，而非顺序读取；设置 `--weight-loader-prefetch-checkpoints` 时默认禁用，以避免与预取线程共同造成输入输出(Input/Output，I/O)资源过度竞争；可将此项设为 `true` 重新启用。 | `true` |
| `auto` / `safetensors` / `pt` / `npcache` | `num_threads` (int) | 启用多线程加载时使用的工作线程数。 | 8 |
| `sharded_state` | `pattern` (str) | 各并行进程(Rank)对应分片的文件名模式(Filename Pattern)。 | `model-rank-{rank}-part-{part}.safetensors` |
| `fastsafetensors` | `enable_gds` (bool) | 使用 GPU 直接存储(GPUDirect Storage，GDS)；主机未提供 NVIDIA GPUDirect Storage 内核驱动时，例如在 gVisor 沙箱中，应设为 `false`。 | `true` |
| `bitsandbytes` | `qlora_adapter_name_or_path` (str) | 在经 bitsandbytes 量化的基础权重(Base Weights)之上应用的 QLoRA 适配器(Adapter)。 | — |
| `runai_streamer` | `distributed`、`concurrency`、`memory_limit` | 流式加载控制项；参见[从对象存储加载模型](https://docs.sglang.io/docs/advanced_features/object_storage)。 | 见链接页面 |

## 权重加载性能参数(Weight-Loading Performance Flags)

以下顶层参数(Top-Level Arguments)用于调优 safetensors 权重的读取方式，与 `--load-format` 独立。

| 参数(Flag) | 说明(Description) | 默认值(Default) |
|---|---|---|
| `--download-dir` | 下载和缓存 Hugging Face 模型文件的目录。 | Hugging Face 默认目录 |
| `--weight-loader-disable-mmap` | 加载 safetensors 时禁用内存映射(Memory Mapping，mmap)；在 mmap 较慢的文件系统上可能有帮助。 | 关闭(off) |
| `--weight-loader-prefetch-checkpoints` | 加载前，将检查点文件预取到操作系统页缓存(OS Page Cache)。每个 Rank 预取部分分片，将共享文件系统(NFS/Lustre)上的网络 I/O 总量从 N × 检查点大小降至 1 × 检查点大小，推荐用于存放在网络存储上的模型。启用后，默认禁用 safetensors 多线程加载，以避免与预取线程共同造成 I/O 资源过度竞争；可在 `--model-loader-extra-config` 中设置 `enable_multithread_load=true` 保留多线程加载，例如在预取为空操作(No-op)的本地 NVMe 存储上。 | 关闭(off) |
| `--weight-loader-prefetch-num-threads` | 每个 Rank 用于检查点预取的线程数。 | 4 |
| `--weight-loader-drop-cache-after-load` | 每成功加载一个分片后，调用 `posix_fadvise(DONTNEED)` 释放页缓存；标准 safetensors 加载器和 `fastsafetensors` 加载器均支持。 | 关闭(off) |
| `--custom-weight-loader` | 自定义权重加载函数的导入路径(Import Path)，例如 `my_package.weight_load_func`；可指定一个或多个路径。 | — |
