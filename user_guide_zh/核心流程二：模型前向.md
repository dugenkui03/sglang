# 核心流程二：模型前向

以 Qwen3.5 Dense 的单卡、纯文本、普通生成路径为例，不额外返回输入 logprob；形状按有效 token 计，省略硬件融合与辅助分支。
两类 Decoder 层按配置依次执行；例如 full_attention_interval=4 时，每三层 linear_attention 后接一层 full_attention（代码名 attention）。

**图一：embedding → Transformer 层 → 最终 norm → LM Head → logits。** 源码：[父类入口](../python/sglang/srt/models/qwen3_vl.py#L1447)、[文本模型](../python/sglang/srt/models/qwen3_5.py#L1522)、[LM Head 计算](../python/sglang/srt/layers/logits_processor.py#L722)。

```text
Qwen3_5ForConditionalGeneration.forward()
  = Qwen3VLForConditionalGeneration.forward()（直接继承的实现）
      ├─ language_model_only=True：self.model(input_ids=...)
      └─ 否：general_mm_embed_routine() → embedding → self.model(input_embeds=...)
                         ↓ 两条路径进入同一个文本模型
           Qwen3_5ForCausalLM.forward()
             → self.embed_tokens(input_ids)：查表得到 [T,H]；已有 input_embeds 则直接使用
             → for layer_idx in range(self.start_layer, self.end_layer)
                 → self.layers[layer_idx](...)：执行图二或图三，逐层更新 hidden_states
             → self.norm(...)：合并剩余残差，执行最终 GemmaRMSNorm
             → 返回 hidden_states[T,H]
                         ↓ 回到外层模型
           self.logits_processor(...) → LogitsProcessor.forward()
             → _get_pruned_states()：选各请求最后一个用于预测的位置 → [B,H]
             → _get_logits() → _compute_lm_head()
             → hidden_states @ lm_head.weight.T：[B,H] × [H,V] → logits[B,V]
             → 返回 LogitsProcessorOutput(next_token_logits=...)
```

T：本轮有效 token 数（prefill 为本轮新输入之和，普通 decode 为 B）；H：hidden_size；B：请求数；V：词表大小。
LM Head 的权重在 LogitsProcessor 内参与计算；logits 是未归一化的词表分数，后续由上层采样选出 token ID。

**图二：全注意力层（full_attention / attention）。** 源码：[Qwen3_5AttentionDecoderLayer.forward()](../python/sglang/srt/models/qwen3_5.py#L1280)。
```text
Qwen3_5AttentionDecoderLayer.forward()
  → layer_communicator.prepare_attn_and_capture_last_layer_outputs()
      → prepare_attn()：衔接残差 + input_layernorm
  → self_attention()
      → forward_prepare_*()：qkv_proj 得到 QKV/可选门控 → Q/K 归一化 → RoPE
      → self.attn(...) / RadixAttention → 后端写 KV cache，用 Q 与当前/历史 KV 计算
      → 输出门控（若启用）→ o_proj：投影回 hidden_size
  → layer_communicator.prepare_mlp()：注意力输出加残差 + post_attention_layernorm
  → self.mlp(...) / Qwen2MoeMLP：gate_up_proj → SiLU 门控乘法 → down_proj
  → layer_communicator.postprocess_layer() → 返回 (hidden_states, residual)
```

**图三：线性注意力层（linear_attention）。** 源码：[Decoder 层](../python/sglang/srt/models/qwen3_5.py#L875)、[Qwen3_5GatedDeltaNet.forward()](../python/sglang/srt/models/qwen3_5.py#L708)。
```text
Qwen3_5LinearDecoderLayer.forward()
  → layer_communicator.prepare_attn_and_capture_last_layer_outputs()
      → prepare_attn()：衔接残差 + input_layernorm
  → self.linear_attn(...) → Qwen3_5GatedDeltaNet.forward()
      → _forward_input_proj()：in_proj_qkvz + in_proj_ba，得到 QKV 与门控信号 z、b、a
      → self.attn(...) / RadixLinearAttention → Gated DeltaNet 后端
          → 因果短卷积处理 QKV，并读取/更新卷积状态
          → 结合历史状态与本轮 QKV、门控信号，计算输出并更新状态
      → self.norm(core_attn_out, z)：归一化与门控 → out_proj：投影回 hidden_size
  → layer_communicator.prepare_mlp()：注意力输出加残差 + post_attention_layernorm
  → self.mlp(...) / Qwen2MoeMLP：gate_up_proj → SiLU 门控乘法 → down_proj
  → layer_communicator.postprocess_layer() → 返回 (hidden_states, residual)
```

两类层的归一化与残差由 [LayerCommunicator](../python/sglang/srt/layers/communicator.py#L505) 协调；MLP 输出的残差相加可融合到下一层输入 norm 或最终 norm，返回的两个张量仍共同表示当前结果。
全注意力保存逐 token 的 K/V；线性注意力使用卷积状态与历史汇总状态，见 [GDN 后端](../python/sglang/srt/layers/attention/linear/gdn_backend.py#L427)。这里的 Qwen2MoeMLP 是普通 Dense MLP。

| 术语 | 全称、中文含义与简要英文释义 |
|---|---|
| Q / K / V | Query / Key / Value，查询 / 键 / 值；attention query, key and value vectors |
| MLP | Multilayer Perceptron，多层感知机；token-wise feed-forward network |
| RoPE | Rotary Position Embedding，旋转位置编码；rotary encoding of token positions |
| RMSNorm | Root Mean Square Normalization，均方根归一化；normalization by root mean square |
| GDN | Gated DeltaNet，门控 Delta 网络；gated recurrent updates of a memory state |
